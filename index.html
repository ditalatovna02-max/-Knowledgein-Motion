Настройки API

Подключите бесплатный или собственный AI-провайдер. Ключ сохраняется только локально.

Ключ хранится только в localStorage вашего браузера и не передаётся никуда, кроме выбранного API.

Как получить бесплатный ключ

  • Groq — console.groq.com → API Keys (быстрая генерация, хорошие лимиты)
  • OpenRouter — openrouter.ai → Keys, модели с суффиксом :free
  • Gemini — aistudio.google.com → Get API key (без карты)

Без ключа приложение работает в демо-режиме с ограниченными примерами. Для реальной генерации по любым темам необходим ключ.
